# 01 智能体设计清单

在整理知识库之前，先完成这份清单。

## 定义基本信息

- [ ] 智能体名称明确。
- [ ] 服务对象明确。
- [ ] 使用场景明确。
- [ ] 维护责任人明确。
- [ ] 发布平台明确或已有候选方案。

## 定义任务范围

- [ ] 能回答的问题类型明确。
- [ ] 不能回答的问题类型明确。
- [ ] 是否可以使用通用知识已说明。
- [ ] 是否需要引用来源已说明。
- [ ] 是否需要代码、表格、模板等输出已说明。

## 定义风险边界

- [ ] 高风险信息类型已列出。
- [ ] 没有依据时的标准回答已确定。
- [ ] 拒答场景已列出。
- [ ] 拒答后的替代帮助方式已确定。

## 定义测试标准

- [ ] 至少 10 个核心回归问题已准备。
- [ ] 高频事实已覆盖。
- [ ] 高风险事实已覆盖。
- [ ] 一个知识库没有答案的问题已覆盖。
- [ ] 一个边界拒答问题已覆盖。
