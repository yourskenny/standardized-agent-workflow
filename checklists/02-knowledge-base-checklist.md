# 02 知识库整理清单

## 资料筛选

- [ ] 原始资料来源明确。
- [ ] 可公开资料和内部资料已分开。
- [ ] 个人隐私和个人作品已排除。
- [ ] 过期资料已删除或归档。
- [ ] 多版本冲突已处理。

## 面向检索整理

- [ ] 核心事实已整理为短句或表格。
- [ ] 高频问题已整理为问答核查表。
- [ ] 用户口语问法已整理为意图映射。
- [ ] 问题和答案尽量在同一片段。
- [ ] 长文档中的关键事实已有独立速查文件。

## 元信息

- [ ] 每个重要文件有 YAML 元信息。
- [ ] `risk_level` 已填写。
- [ ] `source` 已填写。
- [ ] `last_checked` 已填写。
- [ ] `upload_to_agent_kb` 已填写。

## 上传清单

- [ ] 上传清单已列出应上传文件。
- [ ] 上传清单已列出不应上传文件。
- [ ] 维护资料未进入用户知识库。
- [ ] 归档资料未与当前资料混传。
