# 04 入库前抽象清单

## 资料归档

- [ ] 原始资料已保存在维护区或原始资料区。
- [ ] 原始资料来源、时间、权限和风险已记录。
- [ ] 原始资料没有直接加入用户可见知识库。
- [ ] 含个人信息、版权材料或历史语境的内容已标记风险。

## 入库前处理区

- [ ] 已建立 `knowledge_base/_pre_ingestion/<source_batch>/`。
- [ ] 处理区 README 说明了用途和不上传原则。
- [ ] 每份资料有摘要卡片或处理记录。
- [ ] 摘要卡片没有保留可直接复制的完整正文或敏感内容。
- [ ] 主题地图说明了这批资料可沉淀的方向。
- [ ] 处理区文件均标记 `upload_to_agent_kb: false`。

## 抽象候选条目

- [ ] 已从原始资料中抽象出规范、方法、流程、检查清单或常见误区。
- [ ] 候选条目脱离了具体个人作品或历史个案。
- [ ] 候选条目仍处于 `review_status: pending`。
- [ ] 候选条目未直接上传。

## 正式入库

- [ ] 通过审核的抽象条目已移入正式知识库目录。
- [ ] 正式条目有完整 YAML 元信息。
- [ ] 正式条目已标记 `upload_to_agent_kb: true`。
- [ ] 正式条目说明了适用范围和边界。
- [ ] 上传清单包含正式目录。
- [ ] 上传清单明确排除 `_pre_ingestion/`、原始资料和逐份摘要。

## 智能体与测试

- [ ] 系统提示词或行为协议已说明新增抽象知识的使用方式。
- [ ] 系统提示词或行为协议已说明不能提供原始资料、范文或敏感内容。
- [ ] 核心回归测试包含新能力测试。
- [ ] 边界测试覆盖“索要原始资料/范文/完整提交件”的场景。
- [ ] 检索测试覆盖“哪些目录上传、哪些目录不上传”的问题。
