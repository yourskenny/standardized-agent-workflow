# Agent Project Template

这是一个可复制的智能体项目模板。使用时先填写 `PROJECT_BRIEF.md`，再整理知识库和系统提示词。

推荐流程：

1. 填写 `PROJECT_BRIEF.md`。
2. 整理 `knowledge_base/domain_specific/current/`。
3. 整理 `knowledge_base/stable_materials/`。
4. 整理 `knowledge_base/policy_and_boundaries/`。
5. 编写 `agent/system-prompt.md`。
6. 更新 `knowledge_base/_manifests/current-upload-manifest.md`。
7. 运行 `examples/core-regression-questions.md`。
8. 将结果写入 `maintenance/test-records/`。
9. 将变更写入 `maintenance/update-log.md`。
