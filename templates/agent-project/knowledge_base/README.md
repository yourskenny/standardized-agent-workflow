# Knowledge Base

本目录保存智能体知识库源文件。平台中的知识库只是发布版本，本目录才是维护源头。

## 目录结构

```text
knowledge_base/
  _templates/
  _manifests/
  domain_specific/
    current/
  stable_materials/
  policy_and_boundaries/
  archive/
```

## 分类原则

- `domain_specific/current/`：当前周期、当前版本、当前学期会变化的资料。
- `stable_materials/`：长期稳定的公共学习资料、方法、示例。
- `policy_and_boundaries/`：长期有效的边界、隐私、合规和拒答规则。
- `_templates/`：维护者复制使用的模板，不上传。
- `_manifests/`：上传清单，不上传。
- `archive/`：历史版本归档，不与当前资料混传。
