# Update Checklist

## 更新前

- [ ] 确认更新类型。
- [ ] 确认资料来源。
- [ ] 确认是否包含隐私或内部敏感信息。
- [ ] 确认是否存在旧版本冲突。

## 更新知识库

- [ ] 更新当前周期资料。
- [ ] 更新长期资料，若适用。
- [ ] 更新边界规则，若适用。
- [ ] 更新 YAML 元信息。
- [ ] 更新上传清单。

## 同步平台

- [ ] 删除过期文件。
- [ ] 上传新文件。
- [ ] 等待索引完成。
- [ ] 绑定正确知识库。
- [ ] 保存并发布应用。

## 测试记录

- [ ] 运行核心回归测试。
- [ ] 补测相关变更问题。
- [ ] 记录失败项。
- [ ] 修复后重新测试。
- [ ] 填写更新日志。
